# JEM - Jewellery Expense Manager (portfolio demo)

Mobile-first expense, approval, payment and reporting app for a jewellery business. Installable PWA, works offline.
All data in this demo is sample data and stays in your browser.

Highlights: 5-role approval chain with self-approval blocking, duplicate-bill detection, cash book vs counter-cash reconciliation,
analyst-style reports with CSV and PDF export, chart tooltips, dark mode.
Tech: vanilla JavaScript, CSS variables, service worker + manifest (PWA). Backend design: Google Apps Script + Google Sheets (not included in this demo).
